# Portafolio Digital — Keyli Alejandra Arévalo Paz

Sitio personal desarrollado con **Next.js, React y TypeScript**, con estilos CSS responsive en una paleta rosa palo, borgoña y crema.

## Requisitos
- Node.js 20.9 o superior
- npm

## Ejecutar en tu computadora
1. Descarga e instala Node.js desde https://nodejs.org/
2. Abre una terminal dentro de esta carpeta.
3. Ejecuta:

```bash
npm install
npm run dev
```

4. Abre http://localhost:3000

## Preparar para GitHub
1. Crea un repositorio nuevo en GitHub (por ejemplo: `mi-portafolio`).
2. En la terminal, dentro de esta carpeta, ejecuta:

```bash
git init
git add .
git commit -m "Primer commit: portafolio digital"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/mi-portafolio.git
git push -u origin main
```

Sustituye `TU-USUARIO` por tu usuario real de GitHub y usa la URL que GitHub muestre para tu repositorio.

## Publicar en Vercel
1. Entra a https://vercel.com/ e inicia sesión con GitHub.
2. Selecciona **Add New → Project**.
3. Importa el repositorio que acabas de crear.
4. Mantén la configuración detectada de Next.js y pulsa **Deploy**.

## Antes de entregar
- Sustituye el espacio circular de la portada por una fotografía tuya, si deseas incluirla.
- Comprueba que el nombre de la institución y los estados académicos estén correctos.
- Añade enlaces a los repositorios o evidencias originales de tus proyectos cuando los tengas.
- El formulario valida y recibe la solicitud en la API de demostración, pero todavía no envía correos. Para eso debes conectar un proveedor de correo y guardar sus credenciales como variables de entorno en Vercel.

## Nota sobre las demostraciones
Las mini demostraciones de regresión y clasificación son didácticas. La clasificación KNN del modal es una regla simplificada y no sustituye el modelo completo del trabajo académico. Los datos son simulados.
